# Board Screenshots

The requirements ask for a board export or screenshots. Save one screenshot per sprint in this folder.

## File names

| File | What it shows |
| --- | --- |
| `iOS-Sprint-1.png` | Board at the end of iOS Sprint 1 |
| `iOS-Sprint-2.png` | Board at the end of iOS Sprint 2 |
| `iOS-Sprint-3.png` | Board at the end of iOS Sprint 3 (final) |
| `Android-Sprint-0.png` | Android setup board |
| `Android-Final.png` | Android board at the end |

## What to capture

- All columns visible (To Do, In Progress, In Review, Done).
- Card titles and owners readable.
- The sprint name or date somewhere in the shot.

## Before you save

- No passwords, tokens, or personal emails visible.
- No browser tabs, bookmarks, or notifications in the shot.
- Crop to the board only.

If a past sprint was not captured at the time, use the board history or `BACKLOG.md` to rebuild it, and label the file `-reconstructed`.
